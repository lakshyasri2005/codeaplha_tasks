# 🎮 Hangman Game – Python

## 📌 Project Overview

This **Hangman Game** is a simple Python-based word-guessing game developed as part of my **CodeAlpha Internship**.

The player has to guess the hidden word by entering letters. The game continues until the player guesses the word correctly or runs out of attempts.

## 🎯 Project Objective

The main objective of this project is to practice **Core Python programming concepts** and develop problem-solving skills through a practical mini project.

## 🛠️ Technologies Used

* 🐍 Python
* Conditional Statements
* Loops
* Functions
* Strings
* Lists
* User Input
* Exception Handling

## 🎮 How the Game Works

1. The program selects a secret word.
2. The player guesses one letter at a time.
3. Correct guesses reveal the letters in the word.
4. Incorrect guesses reduce the number of remaining attempts.
5. The player wins by guessing the complete word.
6. The player loses when all attempts are used.

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the following command in the terminal:

```bash
python hangman.py
```
